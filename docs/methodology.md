# Methodology

This project is mainly concerned with the encoding of data into a quantum circuit and its impact on a learning
agent's ability (classical or quantum) to learn said data. Because achieving the maximum accuracy on some
real-world dataset is not the main focus, the dataset is artificially generated (by what is called a generator)
in order to restrict the learner's hypothesis class, and then this dataset is learnt (by a classifier).

## 1. Data generation (`datasets.py`)

The synthetic dataset is generated in a manner similar to [1804.11326]. The data are generated by creating a set
of random points in [0, 2π]². Then this set is fed into a PQC of 2 qubits that rotates each qubit *i* by a set
amount *xᵢ* in each direction (Rx, Ry, Rz), followed by a random unitary U. The label comes from the expected value

⟨C₂ Z(x₁, x₂) C₂⟩

where C₂ is a CNOT gate with qubit 2 as its target and Z(x₁, x₂) rotates by an angle f(x₁, x₂) in the
z-direction. The specific form of this function changes the shape of the classification:

| Dataset | Name in the code | f(x₁, x₂) | Shape |
|---|---|---|---|
| 1 | `linear` | x₂ | linearly separated |
| 2 | `difference` | x₁ − x₂ | two decision boundaries need be drawn |
| 3 | `product` | x₁x₂ | even more complex wavy dataset |

Points with an expected value of at least 0.3 get label 1, at most −0.3 label 0, and in between a random label.
Afterwards the dataset is balanced so that both classes are represented equally (500 points each).

## 2. The classifiers

Both classifiers have 3 inputs (3 qubits for the PQC and 3 input neurons for the NN), as we want to encode both
x₁ and x₂ as well as a combination of x₁ and x₂ (x₁x₂), as a kernel method to make the classification easier.

### PQC (`quantum_circuits.py`)

The PQC is comprised of an encoding part S(x) and a variational part W(θ). Three different encodings are tested:

- Encoding 1: S(x) = Rz(x)
- Encoding 2: S(x) = Rz(x) Ry(x)
- Encoding 3: S(x) = Rz(x) Ry(x) Rz(x)

The variational part is made of Rx rotations on every qubit and CZ gates between neighbouring qubits; each
sequence of rotations + CZ is one variational layer, with 3 trainable parameters. The output is the amplitude of
the |111⟩ state, and a point is classified as 1 if it is above 0.5. A square loss function is used and it is
optimised with "COBYLA", as the derivatives of the loss function cannot be accessed by a classical optimizer
(at most 80 iterations).

The circuits are small (2 and 3 qubits), so they are simulated directly with numpy instead of cirq or pennylane.

### Neural network (`classical_models.py`)

The classical classifier is a fully connected feed-forward neural network with 3 input neurons and l layers of
3 neurons each (to be as equivalent as possible to the PQC). The loss function is binary crossentropy, the
optimizer adam, and the model runs for 80 epochs. It is built with scikit-learn (the Keras version is in
`build_keras_mlp`). The inputs are standardised first.

## 3. Experiments (`training.py`, `evaluation.py`)

The data are split 50/50 into a training and a test set. Every model is trained on the training set and the
accuracy is measured on both sets. The models are named as in the table of the report: 'S' and 'D' denote the
type of architecture (shallow = 1 layer, deep = 5 layers) and 'E1,2,3' the encoding scheme used for the PQCs
(SNN, DNN, SE1, SE2, SE3, DE1, DE2, DE3).

The report used one run per model. As said in its Further Work section, statistical anomalies due to the
networks' starting weights may affect the results, so here the whole set of experiments is repeated for 10
seeds and the accuracies are averaged (`results/benchmarks.csv`).

## 4. Changes from the original notebook

- The labels are 0/1 everywhere. The original code compared −1/+1 labels with 0/1 predictions, which caps the
  accuracy at 0.5.
- The labelling of the generator had two `if` statements in a row, so points with an expected value ≥ 0.3 ended
  up with a random label. Fixed with `if / elif / else`.
- The random unitary U was drawn again for every point; now it is drawn once per dataset.
- SMOTE created new points whose labels did not come from the generator; now points are drawn until both
  classes have 500 examples.
- The NN inputs are standardised: without it the x₁x₂ input (up to ~39) makes the 5-layer NN predict a single
  label.
- Code that was not used for the results (the `Z1Z2` gate, the `Circuit`, `Experiment` and MNIST `Network`
  classes) was removed. The original is in `notebooks/legacy/`.
